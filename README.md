# 🎓 Student Performance Predictor with Graph

## 📌 Project Overview

This project predicts student marks based on study hours using **Machine Learning (Linear Regression)** and displays the result using a **Streamlit web app**.
The app also shows a **graph visualization** of the dataset and prediction.

This project demonstrates:

* Machine Learning model training
* User input prediction
* Data visualization
* Streamlit deployment

---

## 🚀 Features

* Predict student marks from study hours
* Interactive user input using Streamlit
* Graph visualization using Matplotlib
* Simple and clean UI
* Real-time prediction

---

## 🧠 Model Used

* Linear Regression (scikit-learn)

---

## 📊 Graph Output

The app displays:

* Dataset scatter plot
* Regression line
* Predicted point

## ▶️ How to Run

### 1 Install dependencies

```
pip install -r requirements.txt
```

### 2 Run Streamlit app

```
streamlit run app.py
```
